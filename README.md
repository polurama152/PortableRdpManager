# Portable RDP Manager

Portable-приложение для Windows, которое создаёт, открывает и редактирует
файлы подключений Microsoft Remote Desktop (`.rdp`), а затем запускает их
через штатный `mstsc.exe`.

## Возможности

- адрес, порт и имя пользователя;
- размер экрана, полноэкранный и многомониторный режимы;
- административная сессия;
- RD Gateway;
- перенаправление буфера обмена, дисков, принтеров, смарт-карт и звука;
- вкладка для прямого редактирования всех параметров `.rdp`;
- сохранение неизвестных приложению параметров исходного файла;
- работа без установки и без прав администратора.

Приложение намеренно не хранит пароль. При подключении пароль запрашивает
Windows; при желании пользователь может сохранить его в Диспетчере учётных
данных Windows.

## Сборка

Нужен .NET 8 SDK. В PowerShell:

```powershell
.\build-portable.ps1
```

Результат: `dist\win-x64\PortableRdpManager.exe`. На целевом компьютере
.NET устанавливать не нужно.

Другие архитектуры:

```powershell
.\build-portable.ps1 -Runtime win-x86
.\build-portable.ps1 -Runtime win-arm64
```

## Запуск из исходников

```powershell
dotnet run
```
